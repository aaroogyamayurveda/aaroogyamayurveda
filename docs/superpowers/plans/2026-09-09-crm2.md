# CRM2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build CRM2 as a zero-cost, isolated teleshopping ERP without modifying CRM1.

**Architecture:** Static vanilla JS frontend plus a dedicated Supabase project with RLS, RPCs and auditable business tables. Optional integrations use server-side adapters and are not required for core operation.

**Tech Stack:** HTML/CSS/ES modules, Supabase JS v2 CDN, PostgreSQL/RLS, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-09-crm2-design.md`

## Global Constraints
- CRM1 at `crm1/` is immutable for CRM2 work.
- CRM2 uses Supabase project `ukpfmlhkvwgoqrrgdump` only.
- Total required software cost must remain ₹0/month.
- Never commit service-role keys, private Google Drive data, or third-party secrets.
- One current production module per responsibility; no v2/v3/final JS accumulation.
- Manual mobile calling must work without VICIdial.
- Database authorization is enforced by RLS/RPC, not UI alone.
